# Атомная Сферическая Математика AtomNET (наша математика, формальный каркас)

## 1. Что за нейронная сеть это

Вес строки слоя `w ∈ Rⁿ` ядра Keraliна — не «обычный» свободный параметр, а
**атом**: четырёхкомпонентное состояние

```
A = (nucleus n, radius r, direction u ∈ Sⁿ⁻¹, shell s)
    w = n·1 + r·u        (1)
```

со схемой разложения `n = mean(w), r = ‖w − n·1‖, u = (w − n)/r`.

**Рекомендуемое имя класса сетей:** *сферические сети с ядром* —
англ. **Spherical-Kernel / Radial-Shell networks (SRN / "electron-shell")**.
Математически это:
- **weight normalization + сдвиг**: направление u и радиус r развязаны как в
  Salimans–Kingma (2016) `w = g/‖v‖ · v`; ядро n добавляет *трансляционную*
  инвариантность вдоль `1 = (1,…,1)` (нулевая мода: сдвиг всех весов строки
  не меняет движение относительно центра);
- **риманова ~ инвариантность**: система инвариантна к автоморфизмам группы
  `SO(n)×R⁺×R` (вращения, масштабы, сдвиги центра).

**Родословная литература:** weight normalization (Salimans–Kingma 2016),
orthogonal RNN (Arjovsky 2016), spherical embedding, Householder Networks,
Spherical Wave neuron models (PHNN), сферические коды и решётки (Shannon).
NPU-инженерная аналогия: каждый атом — один «макроатом» фиксированного размера,
который удобно маппить в стек JIT: ядро — скалярный регистр, радиус — 1 строка,
направление — упакованная кольцевая сфера.

**Родословная квантовых знаний, изучённых по исходникам:**

- *Fubini–Study / Bures метрика* на CPⁿ: `ds² = ⟨dψ|dψ⟩⟨ψ|ψ⟩ − |⟨dψ|ψ⟩|² / ⟨ψ|ψ⟩²`.
  Для ядра-направления u ∈ Sⁿ⁻¹ аналог: `ds² = ⟨du,du⟩ − ⟨du,u⟩²` (точно те же
  операции — перпендикулярность; проекция P_u(g) = g − (g·u)u — это тангенциальная
  проекция, как в quantum geometric learning).
- *Квантовый угол alfa*: `cos γ(ψ,φ) = |⟨ψ|φ⟩|/(‖ψ‖·‖φ‖)` — на Sphere это arccos(dot);
  shell-коды дают дискретизацию квантового угла (сферический код = разбиение Sphere).
- *Hopf fibration* `S¹ → S²ⁿ⁺¹ → CPⁿ`: расслоение нормирующих фаз;
  ядро+радиус — аналог дилатации (R), направление — фаза; извлечение u из w — то же расщепление.
- *Shell-квантование*: в атоме электроны занимают оболочки (орбитали на сфере);
  наша кольцевая кодовая книга (M×K) — та же идея: дискретизация угловых состояний.

## 2. Формальные определения

### 2.1 Объекты

- `n ∈ R` — ядро (нулевой	mode строки).
- `r ∈ R≥0` — радиус.
- `u ∈ Sⁿ⁻¹ := {u ∈ Rⁿ: ‖u‖ = 1}` — направление.
- `s ∈ Z_M×K` — подпись оболочки (SFEROM tri-score: cosine/hamming/jaccard; см. `sferom.rs`).

**Инварианты:**
I1. Знаковая инвариантность: w инвариантен к (n, u) → (n±c, r·(−u)) при смене знака.
I2. Норм-инвариантность: при reparametrize поверхности
ε-регуляризация радиуса ставятся малые значения ~1e-12 (r < min_radius — переобразование в направление/нейро-kernel).
I3. Вид: вырожденный градиент на r = 0 (u не определён) -> известная точка наложения-особенности,
убирается через keralin sig-/coldtype и теплый запуск.

### 2.2 Динамика (геодезическая)

Направление обновляется **точным геодезическим шагом** на Sⁿ⁻¹:

```
v = P_u(g)T ( касательная компонента, P_u(g) = g − (g·u)·u )
θ = lr·|v|
u' = cos θ·u + sin θ·(v/|v|)              (2)
уравнение непрерывного времени: du/dt = P_u(−∇L)
```

**Теорема (NORMSAFE):** |u'| = 1 с точностью до f32; θ = lr·|v| — расстояние
по большой окружности при шаге lr.

## 3. Инженерные метод-де ви обрезки трей-อฟфы

**Плюсы:**
- стабильность: нет «Взрыва» нормированных слоёв; деградация только на направлениях;
- compression: квантование направления по ±shell-коду = 2.5x-4x звука строка (см. сферическая码 книги; SFEROM по качества);
- арифметика CPU: касательная проекция — один dot+axpy — да вылтAVX2->~0.5x vs отдельная порция dot;
- Single/NPU фит: архитектура ядра хорошо ложится на JIT 6x16 tiles (ряд-атом = плитка).

**Риски/границы:**
- сингулярность r=0: атомы "коломбека" нового нейрфортаff;
- изменениенегеосими: геометрический шаг дороже normalize-проекции на ~ (cos+sin scalar) и на 1 нормализацию (?) минимум;
- ёмкость-жёсткость: при очень плотных распределениях направлений, shell-квантование может регрессировать качества (короче — при масштабах в 10B нужна неточная оценка подхода, как атомная упаковка Q8-Q0).
