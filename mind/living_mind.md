# Живой разум Луны (Living Mind)

Не «настройка, как мы хотим», а автономная структура, которая сама решает:
что ей интересно, что повторить, что проверить, когда отдыхать.

## 1. Побуждения (drives) — внутри, не извне
| Побуждение | Смысл | Растёт | Падает |
|---|---|---|---|
| Любопытство (curiosity) | новизна тем/входов (XOR-hamming!) | при новом сигнале | после изучения |
| Мастерство (mastery) | уверенность в знакомых темах (гейт/verifier) | при PASSED | при GARBAGE/ошибке |
| Энергия (energy) | бюджет «внимания» (Hexiron-физика) | после отдыха | при генерации |
| Связность (coherence_ema) | согласованность с памятью (RingMemory) | повтор значимого | противоречие |

## 2. Цикл саморешения (каждый шаг N)
```
1. Ощутить (sense): XOR-подпись входа/памяти → новизна hamming
2. Решить (decide): выбрать действие по побуждениям:
   - если curiosity высока → GENERATE: самовопрос по теме интереса
   - если mastery низкая у темы → REPLAY: повторить из RingMemory
   - если есть кандидат → VERIFY: гейт/ReasonGraph (математика)
   - если energy низка → REST: сон-консолидация (slow-веса)
3. Действовать: генератор слов/ответов по теме (self-generated corpus)
4. Учиться: верное → в память и тренировку (само-примеры, RFT-стиль)
5. Отражать: лог «что решила и почему» (метакогниция из deep-research)
```
Решения принимает сама модель по своим побуждениям — мы только задаём
механику, не содержание шагов.

## 3. Генераторы слов/тем (самопорождение содержания)
- Банк тем-семян + комбинаторы шаблонов (число+действие+настроение)
- Новизна: XOR-подписи недавних генераций → редкие темы получают приоритет
- Само-примеры становятся обучающими (self-play): «думает → проверяет → учится»

## 4. Честная рамка
Это каркас **автономного самообучения** (свои цели, свой выбор данных,
своя проверка) — не утверждение о сознании. «Живость» = петля
sense→decide→act→learn→reflect на реальной математике и языке,
управляемая внутренними побуждениями, а не внешним датасетом.
